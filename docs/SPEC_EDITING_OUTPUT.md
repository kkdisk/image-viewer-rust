# 0.6.0 裁切、尺寸與輸出契約

日期：2026-10-23。依使用者開始 0.6.0 的授權實作；沿用主規格及開發前評估，0.7.0 調色功能不納入本版。

2026-10-23 追加拍攝相機：背景唯讀讀取 EXIF Make／Model，資訊分頁與浮窗在拍攝時間下方顯示「拍攝相機」。只有品牌或型號時顯示已知部分，兩者皆缺少／空白／無效時省略整列；型號已含相同品牌前綴時不重複品牌。不推測來源相機、不讀廠商專屬 MakerNote，也不寫回來源。沿用文字清理、有效 UTF-8、控制字元與 64 位元組限制；不影響日期排序、方向校正或輸出規則。

使用者追加 EXIF 拍攝時間與自動旋轉：資訊面板在背景讀取 `DateTimeOriginal`、小數秒及時區；未記錄時區時保留相機當地時間，不假設 UTC 或台灣時區。缺少有效拍攝時間時可顯示數位化／EXIF 修改時間，但必須標示來源，禁止冒充拍攝時間或使用檔案修改日期代替。載入沿用 EXIF 1–8 的方向校正，涵蓋鏡像與旋轉，原始檔案不回寫；無效／缺少方向維持像素原方向。輸出不保留舊方向標籤，避免再次旋轉。

- 歷史最多 20 步，預設軟預算 512 MiB。原圖與目前底圖必留，以共享配置識別去重；先汰換最舊過去節點，調低預算仍超限才移除最遠未來節點。復原／重做不觸發汰換。介面列出保留量、可用步數及必要影像超限；不宣稱程序硬上限，預覽／工作中間值另計。
- 一次一種編輯草稿。幾何編輯期間停用微調與比較；進入工具前必須處理既有預覽。工具切換、離開、儲存或取消，均不得默默套用或丟棄草稿。切圖／關閉沿用離開保護；保存前未套用草稿要求先套用或取消。
- 草稿綁定文件世代與已提交節點 ID；像素工作最多一項執行中及一項最新等待，結果有界。取消使舊結果失效，不承諾中止已開始的像素運算。套用最新完整結果只建立一個歷史節點。
- 裁切採已校正方向的目前底圖整數座標，左上含、右下不含；自由、原比例、1:1、4:3、3:2、16:9。反向拖曳正規化並限於圖片，支援框線拖曳、邊角調整、數值修改，拒絕空範圍。螢幕換算使用完整影像矩形，不使用紋理尺寸；固定比例最多一像素取整誤差。
- 改尺寸提供寬高、鎖定比例、百分比與最近鄰／雙三次。使用者最後修改的欄位為主，另一欄四捨五入且至少一像素；百分比以進入工具時尺寸為基準。配置前驗證正數、溢位及既有 64M 像素上限。雙三次透明邊界以預乘 Alpha 處理。
- 幾何編輯完成後重設適合視窗；原圖比較保留完整開啟原圖，不能宣稱裁切後座標自動對齊。顯示取樣、放大鏡與輸出各自維持原契約。
- 新增匯出副本，以 PNG／JPEG 為首批明確選項；JPEG 品質 1–100，預設 90，透明背景預設白色且可選。PNG 保留 Alpha；JPEG 於既有 8 位元通道數值空間做背景合成，未改色彩空間預設。既有儲存／另存保留格式入口，透明 JPEG 同樣採明確背景策略。
- 所有輸出先確認目標；匯出副本不改來源、歷史或已儲存節點。原有儲存／另存成功才標記已儲存。壓縮來源不能寫回解壓管理根目錄；動畫轉靜態及 JPEG 重壓縮警告繼續有效。
- 不複製來源 EXIF、GPS 或未知 ICC；方向已烘焙於像素，介面明示不保留來源元資料。未知副檔名不能默默寫出 PNG。
- 使用同目錄暫存檔；編碼成功且關閉寫入後才替換，不先刪除來源。替換失敗保留來源，不採先移走唯一舊檔的備份交換。失敗、取消及過期結果不改文件狀態。
- 單元／整合驗證涵蓋預算、草稿失效、座標／DPI、透明重採樣、輸出重讀及失敗保護；原生桌面、CI、封裝各自記錄，不以自動化代替桌面驗收。
