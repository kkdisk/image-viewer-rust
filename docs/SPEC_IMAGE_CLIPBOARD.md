# 0.8.0 影像剪貼簿契約

日期：2026-10-23。使用者已授權加入複製圖片及整理已實作／預計功能清單；接續未發布的 0.8.0，不更動既有標籤。

## 行為與邊界

- 「編輯 → 複製圖片」及 Ctrl+C 複製目前開啟文件已套用的完整解析度 RGBA8 影像；不複製縮圖、縮放後畫面或外部參考圖。壓縮檔來源也可複製目前已開啟圖片，不寫回來源。
- 有未套用微調、裁切／改尺寸草稿、正在載入／變形／儲存或離開確認時拒絕，提供提示；沒有圖片時停用選單。文字欄位取得輸入焦點，或標籤已有文字選取時，Ctrl+C 保留文字複製；因 egui 標籤直到幀結束才產生 copied_text，派送前須檢查 LabelSelectionState，不能只檢查鍵盤焦點或當下輸出；Ctrl+Shift+C 保留來源路徑。
- 同時只容許一項背景複製，連按不排隊；持有請求當時已套用影像的 Arc 快照，後續切圖、復原或編輯不改變該次內容。成功／失敗回報快照檔名及尺寸，不改編輯歷史或儲存狀態。關閉時如仍在複製先提示等待，完成後可再關閉。
- 原始 RGBA 大小上限 128 MiB，超限拒絕並提示先改尺寸，不偷偷縮小。此限制不是程序總記憶體上限；原圖、系統剪貼簿、PNG 編碼及格式轉換會額外使用記憶體。
- Windows 使用已鎖定 arboard 3.7.0 的 image-data 支援，直接依賴限 Windows；沿用既有 image 的 PNG／BMP，無新增 C/C++ 動態依賴或手寫 unsafe。以 PNG 與 DIBV5 交付，保留 RGBA；接收端透明度及貼上格式仍取決於其支援。不複製 EXIF、GPS、檔案路徑或檔案本體。
- 系統剪貼簿正在被其他程式占用時明確報錯，讓使用者重試；成功後再貼上。其他作業系統先顯示未支援，不宣稱跨平台驗收。

## 切片及位置

- D0：本契約、tasks 進度、依賴核對；版本維持未發布 0.8.0。
- D1：image_clipboard 模組、受控單項背景寫入、快照／上限／失敗及關閉保護。
- D2：編輯選單、同源快捷鍵與 Event::Copy 轉接、固定狀態列提示。
- D3：FEATURE_CHECKLIST、README／CHANGELOG／規格索引／候選評估同步。
- D4：快照與 RGBA、過大／預覽／忙碌拒絕、原生 Copy 事件及文字焦點、自動化／Clippy／發布建置與封裝；原生系統貼上另驗。

## 驗證方法

自動測試使用可注入的剪貼簿寫入端，避免覆蓋使用者當前剪貼簿；檢查實際 RGBA 與快照、單項限制及錯誤回報。原生桌面請實際由選單及 Ctrl+C 複製透明 PNG、直式 JPEG、已套用編輯及壓縮來源，貼至支援影像的應用，確認尺寸、方向、顏色及透明度。輸入欄位選字後 Ctrl+C 不得改成影像。自動化不等同已驗收系統貼上。
