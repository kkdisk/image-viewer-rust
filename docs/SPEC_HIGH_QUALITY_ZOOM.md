# 0.5.2 高品質放大

本補充契約依使用者同意的縮放取樣建議實作，沿用主規格第 8 節與資源治理規格。不新增依賴；只改顯示紋理，不改已儲存檔案色彩空間、完整底圖、歷史或輸出像素。

## 操作與預設

「檢視 → 縮放取樣」提供三種模式，記入既有偏好設定；缺少新欄位的舊設定預設採高品質。

| 模式 | 行為 |
|---|---|
| 快速（雙線性） | 維持原圖可見區域與原有下採樣；GPU 雙線性顯示，不先擴大像素 |
| 高品質（雙三次），預設 | 縮放／平移時先快速顯示；視口、來源、DPI 與模式穩定且沒有滑鼠按下／滾輪活動 150 毫秒後，在背景以 Catmull-Rom 放大可見區域 |
| 像素（最近鄰） | 可見區域使用最近鄰下採樣及 GPU 最近鄰顯示，不先擴大像素 |

主圖、原圖比較與外部參考圖共用模式；全螢幕沿用選定模式。局部放大鏡維持原本像素檢視功能。

## 取樣及交付

- 高品質目標依原圖可見區域、縮放比例與每邏輯點的實體像素數計算；含 DPI，維持原有百分比定義，不額外改動縮放／平移座標。
- 僅在目標大於原圖可見區域時重採樣放大；100% 且 DPI 為 1 時保留原生像素，不重複插值。縮小時沿用既有顯示下採樣。
- 所有模式受裝置上限、單邊 4096 與每張 RGBA8 紋理 64 MiB 限制。預算不足時限制顯示解析度，不能承諾所有極高倍率都有完整目標顯示解析度。
- 透明圖以預乘 Alpha 的顏色插值，再還原顯示 RGBA，避免完全透明像素的隱藏顏色滲入邊緣。原圖與輸出不經此轉換。
- 來源 Arc、裁切區域、上限、取樣模式與目標尺寸共同識別結果。等待請求僅留最新一筆，結果通道有界；切圖、模式切換、縮放或平移後只交付仍有效的結果。
- 等待重繪時沿用已有紋理；耗時計算在背景執行，不宣稱已開始的舊取樣會中途停止。CPU 暫存與同時保留的新舊紋理不等於整個程序有 64 MiB 硬上限。

## 驗收

自動化覆蓋：100%／250%／400% 與 Catmull-Rom 像素一致、透明隱藏色、原圖不變、150 毫秒時鐘、微小平移重設計時、DPI、GPU 小上限與紋理預算、過期模式／來源隔離、快速與像素取樣、舊偏好相容與寫入重讀，以及主圖／雙圖／參考圖顯示後的完整像素另存。

原生桌面待驗：相同照片於 100%／250%／400% 比較三種模式，停止縮放後的畫質、快速拖曳的回應、透明圖邊緣、不同 Windows DPI、全螢幕與雙圖比較。測試與延後排程間隔不代表已量測達成 60 FPS；實際照片畫質及 GPU 效能仍需原生驗收。

核心取樣使用既有 [image 0.25.10 的 CatmullRom](https://docs.rs/image/0.25.10/image/imageops/enum.FilterType.html)。
