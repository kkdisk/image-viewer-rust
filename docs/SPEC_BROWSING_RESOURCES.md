# 0.4.0／0.5.0 資源與瀏覽契約

日期：2026-10-22。依 ROADMAP 第 6、7、11 節及使用者接續實作授權，補充現行規格；P3 歷史預算及 v0.5.x 編輯／整理功能維持後續範圍。本次整合套件版本為 0.5.0，包含 0.4.0 的資源治理，尚未發布新標籤。

## 資源工作與預算

- 縮圖使用兩個背景工作、32 筆工作及 32 筆結果通道，介面最多追蹤 34 個待交付項目。解碼仍受 64M 像素上限保護，失敗有短暫重試節流，不會於每一幀反覆解碼。
- 縮圖紋理依最近使用汰換，預設 16 MiB 與 512 筆雙重上限；容量按 RGBA 像素估計，不包含鍵、配置器、驅動、正在解碼的來源及其他工作。80×80 全尺寸縮圖在 512 筆時約 12.5 MiB，低於位元組上限。
- 同目錄切圖沿用快取；目錄或受管理壓縮來源範圍改變會增加世代並使舊結果失效。可見縮圖在畫面更新時以兩秒節流於背景核對長度及修改時間，解碼前後版本不一致則拒絕交付。這不是檔案監看；不保證偵測刻意保持長度與修改時間的內容變更。
- 顯示依實際視口、縮放、像素密度及裝置上限選擇層級。放大時只對可見來源區域加邊界量產生背景裁切；畫布將紋理映射回完整影像座標，放大鏡與儲存仍使用完整原始像素。
- 顯示紋理單邊預設最多 4096 且不超過 GPU 上限，單張 RGBA 紋理估計最多 64 MiB；顯示工作只保留最新等待快照及有界結果。來源、歷史、CPU 轉換中間值及交付前後紋理不計入此單張上限，不能稱為程序硬記憶體上限。超過此顯示預算的高密度視口仍會下採樣。
- 原始開啟、完整尺寸輸出、未套用預覽與記憶體 Undo 契約不變。縮圖、顯示重採樣及檔案資料查詢不在介面執行緒執行。

## 瀏覽與排序

- 啟動接受一個圖片、資料夾或壓縮檔路徑，支援 Unicode、空白、`--portable` 與 `--`。相對路徑於啟動時轉為絕對路徑；未知參數或多個路徑顯示錯誤。
- 選單、最近清單、拖放與啟動開檔共用離開保護。背景辨識資料夾與壓縮來源，名稱以 `.zip`／`.7z` 結尾的資料夾仍能開啟；新請求或取消使舊辨識及解碼結果失效。空目錄、缺檔或損毀檔不替換目前工作。
- 預設自然檔名排序，另有修改日期、大小及升降冪。數字段以字串長度與值比較，避免超過 u64 範圍時溢位；英文字母大小寫不敏感，相同值以名稱及完整路徑決定穩定次序。
- 日期／大小來自背景檔案資料快照，未知值排最後。壓縮清單也使用相同排序；其日期／大小為受管理解壓檔的資料，不宣稱保留了原始壓縮標頭的日期。變更排序保持目前檔案及選取，排序方式寫入偏好。

## 全螢幕與按鍵

- F11 切換全螢幕，保留一般面板開關與一般視窗大小，隱藏選單、狀態列、縮圖列、微調及比較工具列；微調控制不出現，也不改寫原有預覽。
- 滑鼠移動顯示檔名、序號與縮放浮層兩秒，到期不保留常駐控制。全螢幕狀態不寫入偏好，原生視窗仍回報全螢幕時也不採其尺寸。
- Esc 先關閉說明、關於、查重或密碼對話框，再離開全螢幕。F11 可直接切換顯示模式；離開／儲存確認仍優先處理，不能繞過文件保護。
- F1 開啟唯讀快捷鍵說明；說明與實際按鍵派送使用同一份定義。文字輸入期間不處理切圖與縮放按鍵。

## 多視窗偏好與最近清單

- JSON schema 由 1 升至 2；載入舊檔時補預設值，較新版本及損毀檔案仍保留且停用本次寫入。
- 最近清單只記成功開啟的來源，不記壓縮密碼或暫存圖片路徑。最多 20 筆，依開啟毫秒時間降冪、同時間按路徑穩定排序；Windows 路徑移除延伸前綴並統一分隔符後以 `CompareStringOrdinal` 忽略大小寫比較。
- 開啟失敗先顯示錯誤，再以移除時間記錄失效項目；最多保留 20 筆移除紀錄，合併時不得讓較舊視窗復活該筆。重新成功開啟的新時間可覆蓋舊移除紀錄。
- 所有寫入使用固定的同目錄 `.lock` 檔及標準函式庫排他鎖；在背景取得鎖後重讀 JSON、合併最近清單與移除時間，再同目錄暫存及原子替換。鎖等待最多三秒，逾時不無鎖覆寫；持鎖行程結束後由作業系統釋放鎖。
- 一般背景提交合併最近清單，保留最後關閉者的一般設定。關閉時對同一工作通道交付最終快照並收束既有工作，最後成功關閉提交的一般設定勝出。關閉寫入失敗會回報原生錯誤訊息，原檔保留。

## 驗證邊界

固定測資方法與原始樣本見 [資源量測](RESOURCE_MEASUREMENTS.md)。目前只有暖快取解碼、CPU 紋理交付及工作集取樣；原生冷啟動、真實 GPU 幀時間、原生首次顯示與乾淨 Windows 操作驗收均為 Unknown。各版桌面流程仍須人工確認，不以單元測試推論達成 50 ms／60 FPS。
