# 0.8.1 儲存與日期篩選修補驗證

日期：2026-10-27。使用者授權依修補建議實作及準備交付，保留 v0.8.0 標籤。

## 行為與審查

同目錄原地儲存或另存完成後，重新掃描的清單保留交付時的日期條件；索引未完成前不暫時顯示不符條件來源。不同目錄另存切換範圍並清除條件。儲存輸出不保留來源 EXIF 的既有規則不變；日期消失時保留開啟文件與條件，按索引結果更新清單。

離開確認前記錄圖片是否原本可見，並將保留條件意圖隨背景請求交付，避免「儲存並繼續」在重建索引期間誤判為使用者明確開啟被排除圖片。明確開啟原先已被篩除圖片仍清除條件。

回歸共四項：原地儲存與索引重建、無日期篩選及後續導覽／不同目錄另存、儲存並繼續、真實 JPEG DateTimeOriginal 於重新壓縮後消失。僅寫入測試暫存檔，不碰使用者照片或剪貼簿。
