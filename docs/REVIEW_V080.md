# 0.8.0 審查修正

日期：2026-10-23。針對使用者貼上的外部審查，先修第 1、2 項並補回歸；保持未發布 0.8.0，尚未提交／標籤／推送。外部報告的測試結論不代替本輪驗證。

## 已重現並修正

1. 日期狀態分歧：原碼在同目錄開啟被篩除圖片會更換清單世代並重掃；F5／焦點重掃交付期間會暫時顯示所有圖片。新增兩項背景整合回歸，均先在原碼失敗。移除 PhotoBrowser.filter，只由 ImagePlaylist 持有條件；背景已知來源即使不可見也不重掃。交付已知另一張圖片時清除條件；同文件重載與目錄重掃則保留條件，完成索引前不洩出其他來源。背景日期結果依交付時目前條件套用，不保留舊條件副本。
2. 標籤選字複製：以真實指標拖曳選取標籤後送出 Copy 事件，證實 wants_keyboard_input 為 false，原碼仍派送圖片動作。回歸先在原碼失敗。改用 egui 公開 LabelSelectionState 偵測既有選字，保留標籤選取與文字複製。不能只在派送前檢查 copied_text，因標籤在幀結束才產生該輸出。明確選單複製圖片仍可使用。

新增第四項回歸區分「未讀取」與「確定無日期」；日期索引完成前，無日期條件不顯示未知來源，且選單尚未完成索引時停用無日期選項。既有背景開圖交付保留最新條件、文字欄位複製及完整影像快照測試續驗。

回歸以自建 PNG 清單及 egui 文字輸出驗證；標籤案例刻意沒有圖片，原碼失敗也不觸碰使用者系統剪貼簿。原生桌面仍需重驗上述操作。
