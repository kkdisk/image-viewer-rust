# 0.8.0 非批次功能建議

狀態：2026-10-23 使用者明確表示暫不需要批次處理。原批次匯出／整理規劃暫緩；本文件列出候選與建議順序，尚未選定或開始實作 0.8.0。

## 建議方向：照片瀏覽與挑選

目前已具備全螢幕、幻燈片、最近開啟、自然排序／修改時間／檔案大小排序、底部縮圖列、雙圖比較、EXIF 資訊及曲線預設集。建議補強「從一個相簿找到照片、快速選出喜歡的、重用常用調整」的流程。

| 建議順序 | 功能 | 實際用途 | 範圍與成本 |
| --- | --- | --- | --- |
| 1 | 依 EXIF 拍攝日期排序與日期篩選 | 多台相機照片檔名不同，仍可按拍攝時間瀏覽；快速找到某天照片 | 中。背景讀取與快取、缺少 EXIF 的回退與時區語意須定義；不可拖慢開圖或在瀏覽中突然重排 |
| 2 | 縮圖網格總覽 | 一頁看更多照片，點選後回到單張；大相簿比底部橫向縮圖更容易定位 | 中。可視範圍載入、沿用快取預算，切換視圖保留位置與選取；不是批次編輯 |
| 3 | 常用調色預設面板 | 將 0.7.0 常用預設釘選於側欄，單張照片一鍵預覽，不必每次選 JSON 檔 | 小至中。先做少量釘選、命名與移除；沿用預覽／套用，不自行改底圖 |
| 4 | 收藏／待挑標記與篩選 | 翻閱照片時標記值得保留或稍後處理的照片 | 中。先做兩種簡單標記，資料存本機索引或旁置檔、不寫原照片；改名／搬移後關聯需先設計 |
| 5 | 複製圖片到剪貼簿 | 直接貼到聊天或文件，省去另存與選檔 | 中。現有僅有來源路徑複製；影像剪貼簿需先審查依賴、透明度與大圖資源限制 |

建議 0.8.0 第一組以「拍攝日期瀏覽＋縮圖網格」為主。如果希望先改善單張調色的操作便利性，則優先做「常用調色預設面板」。收藏與影像剪貼簿可後續加入，避免一次擴大版本範圍。

## 明確邊界

- 以上均為看圖、找圖及單張預覽，不包含批次輸出、批次調色或自動搬移檔案。
- 拍攝時間缺少時區時保留相機當地時間，不擅自宣稱不同相機已精確同步；缺少 EXIF 的照片須可識別，不悄悄混用修改時間。
- 網格及日期讀取採有界背景工作，來源圖片與壓縮檔唯讀規則保持。
- 標記或常用預設均不直接修改原圖；離開仍走未儲存與預覽保護。
- 自動色階／白平衡仍需固定相機測資與主觀品質驗收，保留獨立候選，暫不把它當作 0.8.0 必備。
