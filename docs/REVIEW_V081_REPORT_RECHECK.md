# 0.8.0～0.8.1 外部審查報告核實

日期：2026-11-11。核對目前 HEAD `c3d60c5` 與使用者貼上的十三項審查；本次僅靜態查證及建議，不修改產品程式。

範圍補註：本表描述讀取時與 HEAD 一致的產品程式。結束檢查時，工作區另外出現 `app.rs`、`document_io.rs`、`file_actions.rs`、`playlist.rs`、`thumbnail_loader.rs` 的未提交修改，包含 256px／64 MiB 縮圖與 `ensure_sort`。這些不是本輪修改，未納入本次驗證；第 1、4 項的最新工作區狀態須另行重審，不能據本表判定新修改已通過。

## 核實結果

| 項次 | 判定與處理建議 |
| --- | --- |
| 1 | 成立：`thumbnail_loader.rs` 固定 80px，總覽沿用同一管理器，格子依寬度配置，容易放大縮圖。256px 可作起點，但 200% DPI 下部分格子仍可能不足；應依實際圖片區像素需求選擇有上限的尺寸層級，並將尺寸納入快取識別。48 MiB 僅為候選預算，另須考慮背景解碼與紋理上傳暫存。 |
| 2 | 成立：縮圖先經 `core_image::load_image` 完整解碼再縮小；32 個等待請求有界，兩條工作執行緒逐一消費，並非同時解碼 32 張。2400 萬像素的記憶體取決於像素格式，96 MB 是 RGBA8 的估算，非所有 JPEG 的固定用量。優化須保留 EXIF 方向、缺少或損壞內嵌縮圖時的回退及資源限制。捲動淘汰須保留仍可見的工作，不宜每幀全面遞增世代。 |
| 3 | 成立但數字需限縮：每個未命中快取的檔案最多讀 512 KiB，小檔案及有效快取會降低實際讀量。一萬張約 5 GiB 是特定條件下的上限估算，並無實測證明改善十倍。先評估漸進讀取；JPEG APP1 不保證位於整個檔案前 64 KiB，分段不能漏掉較後方的 EXIF。四執行緒建議涉及現行單一索引工作執行緒契約，需另行評估。 |
| 4 | 成立：`install_loaded_image` 在同 catalog_revision 交換最新介面清單後，仍無條件呼叫 `set_sort`。可在該分支跳過排序；若在 playlist 內普遍加入跳過條件，必須同時追蹤日期、屬性與來源清單變更，不能只比較排序選項。 |
| 5 | 成立：`set_captured_dates` 經 `set_sort` 重建可見清單，交付端再呼叫 `set_date_filter` 重建一次。可合併交付並維持以目前文件路徑恢復選取的語意。 |
| 6 | 成立：`on_hover_text(format!(...))` 在可見格子每幀預先配置字串；延後至懸停閉包組字即可。屬低風險小型優化。 |
| 7 | 成立為流程一致性建議：直接開圖路徑未傳 preserve_filter，確認離開路徑有傳；目前可見圖片仍由 select_opened_file 正確選取，尚未據此重現功能錯誤。應與第 10 項一起整理並保留儲存後篩選回歸。 |
| 8 | 維護風險成立，目前錯誤未成立：`format_exif_datetime` 已檢查固定長度、ASCII 數字及日期，再產生 YYYY-MM-DD 前綴；目前索引並非直接切割任意外部字串。不宜將假設未來格式改動的風險寫成現有可觸發 panic。可補共用日期鍵與格式契約，暫無必要為此新增日期套件。 |
| 9 | 成立：版本檢查與進度 store 分離，上一輪可能短暫覆寫新工作進度；結果交付仍有 id 核對。若採單一整數打包，需定義工作識別及計數的位元限制與溢位策略。 |
| 10 | 合理的重構候選：型別化開圖角色與篩選政策可減少布林參數誤用，應獨立於效能修補實作。 |
| 11 | 合理的重構候選：明確索引狀態可減少欄位組合，但目前報告沒有提供可重現的不一致狀態；不是已證實的功能缺陷。 |
| 12 | 可維護性建議：網格格子繪製可抽出；檔案長度是檢視訊號，不能僅憑行數判定必須拆分。移動開圖流程須同時降低耦合，避免只搬移程式碼。 |
| 13 | 合理：現有日期驗證可保留；縮小 dead_code 豁免範圍可另做；剪貼簿單工作限制下不需先改執行緒模型。 |

## 建議批次與驗證

1. 首批：第 1、4 項。保留膠卷列的小縮圖成本；針對總覽高 DPI、尺寸層級切換及預算驗收。排序需覆蓋同清單導覽、載入期間改排序／日期索引交付，以及新清單安裝。
2. 次批：第 3、5、6 項。日期讀取覆蓋較後方 APP1、無 EXIF、損壞及讀取中檔案異動；量測冷快取與暖快取，效能數字通過量測後才定論。
3. 後續：第 2 項縮圖解碼與可見工作淘汰；第 7、10 項開圖流程整理；第 9、11 項進度／狀態模型。分批維持可審查範圍。
