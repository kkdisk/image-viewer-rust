# 意圖聲明：純 Rust 圖片瀏覽與編輯工具移植

**狀態**：已確認 (Confirmed)  
**記錄日期**：2026-10-21  

---

## 1. 核心意圖 (Intent Summary)

* **目標成果 (Outcome)**：以純 Rust 開發全新且獨立的桌面圖片工具，實現極致輕量（單一獨立二進位檔、體積 < 15MB）、瞬間啟動（< 50ms）與高幀率的流暢瀏覽與編輯體驗。
* **主要使用者 (User)**：追求高效能、低資源佔用，需要快速看圖、非破壞式即時微調、雙圖對照及批次找出重複圖片的使用者。
* **為什麼是現在 (Why Now)**：原 Python + PyQt6 架構打包體積龐大（> 100MB）、啟動延遲明顯、且現有主視窗（`editor_window.py`）承載過多職責。先前透過 `rust_ext` 已驗證 Rust 在影像微調與雜湊演算法上的巨大效能優勢（速度提升達 10x~100x），現在是將全應用升級為原生架構的最佳時機。
* **成功標準 (Success Criteria)**：
  1. 產出單一原生可執行檔（`.exe`），無需安裝 Python 或額外執行期依賴。
  2. 冷啟動進入首頁時間 < 50ms。
  3. 平移、縮放、雙圖同步操作在高更新率螢幕維持 60 FPS 以上流暢度。
  4. 完整相容並精確對齊現有影像微調（白平衡、亮度、對比、飽和度）、雙圖比較、Undo/Redo 與重複圖片比對功能。
* **關鍵約束 (Constraint)**：
  * 首版預覽計算以 CPU + Rayon 為主，確保預覽與儲存輸出 100% 像素一致。
  * 記憶體快照改用 In-Memory Command Pattern / 參照，杜絕舊版每次 Undo 寫入磁碟 PNG 的 I/O 開銷。
* **明確排除範圍 (Out of Scope)**：
  * **多媒體影片播放與影片縮圖**（徹底移除 QtMultimedia 與相關影片播放器邏輯）。
  * **Python / PyQt 舊架構維護**（不維護 PyO3 綁定或雙軌混合包裝，在新倉庫中全新開局）。
