## 功能入口

| 功能 | 入口 |
| --- | --- |
| 日期／總覽 | 主工具列「縮圖總覽」「日期篩選」 |
| 圖片剪貼簿 | 編輯 → 複製圖片；Ctrl+C |
| 路徑文字 | 編輯 → 複製來源路徑；Ctrl+Shift+C |
| 曲線／資訊 | 右側「調整／資訊」分頁 |
| 預設集 | 工具 → 匯入／匯出調色預設集 |
| 裁切／改尺寸 | 編輯 → 裁切圖片／變更圖片尺寸 |
| 副本輸出 | 檔案 → 匯出副本 |
| 幻燈片／全螢幕 | 空白鍵／F11；F1 查看完整快捷鍵 |
