# 0.7.0 曲線與調色預設集契約

狀態：2026-10-23 使用者授權接續下個版本。以 0.6.1 為基線，依 ROADMAP B0–B5 執行；0.6.1 標籤固定指向其發布提交。

## 範圍與依賴

- B0：正式規格、基線與版本進度。B1：保形平滑曲線及 LUT。B2：曲線編輯與共用調色預覽。B3：版本化 JSON 預設集。B5：歷史／切圖／輸出整合驗收。
- B4 自動色階／白平衡依前次評估保留為 0.7.x：尚無相機固定測資的主觀品質驗收，本版先完成可精確驗證的曲線與預設集。
- 不引入外部動態依賴，不更動既有色彩空間，沿用 RGBA8、Rayon、有界像素工作及背景檔案 I/O。

## 曲線契約

RGB 總曲線及 R／G／B 各通道曲線，每條 2–16 個整數控制點，輸入／輸出皆在 0–255；輸入位置嚴格遞增，第一點輸入為 0、最後為 255。允許輸出遞減以支援反相；端點輸入不可刪除或移位。無效控制點必須拒絕，不自行排序或忽略。

各曲線產生 256 項 LUT，預設使用保形三次 Hermite 平滑插值，控制點斜率連續且不超出相鄰輸出範圍；取整採四捨五入。兩端點曲線維持直線，恆等曲線逐位元組不變。圖形繪製與像素 LUT 共用相同取樣；保留可選折線模式。固定順序：既有白平衡及微調 → RGB 總曲線 → 各通道曲線。Alpha 完全保留，包含完全透明像素。此為既有編碼 RGB 數值上的調整，非新增色彩管理。

曲線併入同一調色參數快照，以已提交底圖重算；既有預覽排程、世代／歷史節點核對、離開保護與套用單一歷史節點均適用。切換通道不改像素；重設單一曲線與重設全部調色分開提供。UI 支援新增、拖曳、刪除內點及數值輸入；鍵盤編輯不得觸發切圖。

## 預設集契約

明確匯入／匯出 JSON，結構版本 1；演算法版本 1 保留折線，版本 2 使用平滑插值。新建調色預設為平滑；匯入舊預設不自動改變原效果，切換模式後才重新預覽。保存名稱、五項既有微調及四條曲線，不含路徑、像素、裁切、尺寸或歷史。檔案上限 64 KiB、名稱 1–80 字元；溫度／色調 -100–100，亮度／對比／飽和度為有限 0–2。拒絕未知版本、未知欄位與無效曲線；驗證成功後才更新草稿並產生預覽。

讀寫在背景執行，單次一個預設集 I/O；匯入結果若圖片或草稿已改變則丟棄。匯出只保存參數快照，不改圖片與儲存節點；限制 JSON 副檔名，既有檔案明確確認，採同目錄暫存替換，未確認的競態用不覆寫替換保護原檔。取消、錯誤及未知新版保留現有草稿與檔案。背景解析真實路徑以拒絕來源圖片別名；預設集 I/O 或覆寫選擇未完成時阻擋關閉，提示完成或取消後再關閉。

## 驗收

恆等／反相／中點與取整、RGB／通道組合順序、非法控制點及 Alpha；曲線單獨草稿的未儲存語意、快速連續工作與切圖失效、套用一次／Undo／Redo／輸出；指標及數值操作、最小視窗與高 DPI；預設集重讀、超限／損毀／未知版本、過期匯入及匯出失敗保護。全工作區測試、Clippy、格式、發布建置及產物版本核對；原生桌面與 CI 證據另列，不沿用舊版結果。
