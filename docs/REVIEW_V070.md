## 其他核對範圍

- 控制點數與端點、輸入遞增、整數折線相容與平滑插值無過衝；圖形與 LUT 使用同一曲線。
- RGB 總曲線後接各通道曲線，Alpha 保持；恆等參數不改像素。
- 有界工作採最新參數快照、Session／歷史節點核對；取消、套用一次、復原／重做與輸出一致。
- JSON 64 KiB 上限、版本／名稱／數值／控制點驗證；舊版折線效果保持；未知欄位拒絕。
- 預設集背景讀寫、同目錄暫存、不覆寫競態保護及已確認覆寫；失敗保留原檔，過期匯入不改草稿。
