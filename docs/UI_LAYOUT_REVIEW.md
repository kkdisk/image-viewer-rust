# 目前介面排版改善建議（2026-10-23）

依使用者提供的兩張實際畫面整理；使用者已授權依此文件實作，版本定為 0.6.1。以下建議已落實於原始碼，原生桌面及遠端 CI 仍需另行驗收。

| 優先順序 | 區域 | 建議 | 預期效果 |
| --- | --- | --- | --- |
| 1 | 底部狀態列 | 將檔名、尺寸、縮放及通知整理為固定兩列；通知使用預留欄位，歷史與記憶體細節移入懸停提示或資訊面板 | 減少底部佔用並避免通知造成畫布跳動 |
| 2 | 右側欄 | 增加「調整／資訊」分頁，圖片資訊改用相同深色樣式；浮窗保留為可選模式 | 避免資訊視窗遮住調整工具，統一視覺 |
| 3 | 調整控制 | 每列統一為「名稱、滑桿、數值」，名稱靠左、數值靠右；增加列間距與可點擊面積 | 提升可讀性及操作精準度 |
| 4 | 縮圖列 | 保留固定高度，可拖曳調整並記住設定；序號與前後張控制合併，選取框保持明確 | 增加圖片空間，減少重複資訊 |
| 5 | 資訊內容 | 優先顯示拍攝日期、尺寸及格式；檔案路徑省略並提供複製，時區與來源方向放入進階區 | 常用資料更容易找到 |
| 6 | 視覺一致性 | 統一深色背景、分隔線、按鈕高度與間距；簡化主要選單為繁體中文，調整次要文字對比 | 降低視覺雜訊並改善閱讀 |

## 0.6.1 實作契約

- 狀態列固定兩列、高度 64 個邏輯點：第一列為文件狀態、檔名與尺寸；第二列為縮放、底圖狀態與預留通知欄。通知限制為一列，懸停可看全文。
- 文件狀態懸停可查歷史步數、512 MiB 軟預算與未計入項目；資訊分頁另有可展開的歷史區。
- 右側使用同一個可調寬度面板切換「調整／資訊」，切換不變更草稿、像素或歷史；「檢視 → 圖片資訊」直接開啟資訊分頁，並保留另開浮窗。
- 圖片資訊的路徑採省略顯示、懸停全文及複製按鈕；拍攝時區與來源方向置於進階資訊。
- 縮圖列高度範圍為 110–220 個邏輯點，上緣可拖曳；縮圖隨列高等比例顯示，偏好沿用既有版本 2 設定格式的可選欄位，舊設定預設 110。
- 圖片序號與前後導航集中在縮圖列；收合縮圖列時，序號顯示於狀態列。
- 主要選單使用繁體中文，明確採用深色主題，避免系統淺色設定覆蓋元件。

驗收重點：通知切換不改變畫布；縮放控制與已儲存狀態語意不變；最小視窗與高 DPI 下不遮蔽套用／取消按鈕；長檔名與路徑不撐寬面板；唯讀資訊不修改原圖。

自動化核對：工作區 154 項通過、3 項預設忽略；全工作區 Clippy、格式及差異檢查通過。新增通知／畫布穩定性、分頁不改草稿與畫布、最小視窗／高 DPI 頁尾可見、縮圖實際拖曳與新介面還原、舊設定高度預設及上下限案例。原生桌面與遠端 CI 待驗／Unknown。
