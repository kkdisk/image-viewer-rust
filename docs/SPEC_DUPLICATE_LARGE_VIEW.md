# 查重大圖檢視補充契約

日期：2026-11-08。依循主規格的背景載入、像素限制與未儲存變更保護。

## 操作與狀態

- 查重預覽卡片的「大圖檢視（暫時收起清單）」開啟該圖片，並以小工具列取代大型清單視窗。
- 主畫布沿用既有滾輪縮放、拖曳平移、原始尺寸與符合視窗操作。
- 工具列可拖曳與摺疊，提供「開啟基準圖」、「開啟比對圖」、「返回查重清單」。基準圖固定為目前群組首張，比對圖沿用清單所選項目；按鈕提示顯示完整路徑。
- 返回按鈕或 Esc 恢復清單，保留掃描目錄、結果、目前群組／圖片與刪除勾選。再次 Esc 關閉清單。
- 工具列的關閉按鈕結束查重介面；從選單再次開啟時顯示清單。
- 所有開圖均沿用主檢視器背景載入與離開保護；若取消未儲存確認，畫布仍維持原圖，可從工具列返回清單。
- 工具列按鈕表示開圖操作，實際載入結果以主檢視器標題、狀態及錯誤回饋為準。

## 驗收

- 指標事件回歸：進入大圖模式後不再繪製大型面板，切圖回傳正確路徑，返回後保留查重狀態。
- 快捷鍵回歸：清單顯示時阻擋主畫布原始尺寸快捷鍵，大圖模式允許；Esc 先返回清單再關閉。
- 原生桌面：確認實際大圖可縮放／平移、工具列可移動／摺疊、切換圖片時未儲存確認可正常取消。
