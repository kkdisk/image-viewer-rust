## Phase 1: 核心計算與狀態底座 (Foundation)

- [x] Task 1.1: 建立 Cargo Workspace 與基礎工程骨架
  - **驗收條件**: 建立根目錄 `Cargo.toml` 與五個子 crate 的目錄結構，配置 edition 2024、LTO、opt-level 3 參數。
  - **驗證方式**: `cargo check --workspace` 編譯通過。
  - **預估規模**: S (2-3 檔案)

- [x] Task 1.2: 實作 `core-image` 影像載入、EXIF 方向校正與安全保護
  - **驗收條件**: 支援主流格式讀取；依 EXIF 自動校正旋轉；長寬乘積超過 64M 像素時返回安全拒絕錯誤。
  - **驗證方式**: 單元測試 `cargo test -p core-image --test exif_and_limits`。
  - **預估規模**: M (3-4 檔案)

- [x] Task 1.3: 移植並強化 Rayon 平行像素運算管線 (白平衡、微調、原子寫檔)
  - **驗收條件**: 移植現有 `rust_ext` 的白平衡與亮度/對比/飽和度平行演算法；實作同目錄暫存檔替換之原子存檔。
  - **驗證方式**: 單元測試 `cargo test -p core-image --test ops_and_atomic_save`，運算結果與原演算法誤差 < 1e-4。
  - **預估規模**: M (3-4 檔案)

- [x] Task 1.4: 實作 `viewer-state` 非破壞式 Session 與 In-Memory Undo/Redo 歷史
  - **驗收條件**: 維護「原圖快照」、「已套用結果」、「調整預覽」三態；Undo 歷史上限 20 步；無磁碟 I/O 開銷。
  - **驗證方式**: 單元測試 `cargo test -p viewer-state`。
  - **預估規模**: M (3-4 檔案)

### Checkpoint 1: 基礎架構檢查點
- [x] 執行 `cargo test --workspace` 全數通過。
- [x] 無 UI 狀態下的端到端流程（載入 → 微調 → 提交歷史 → Undo → 原子寫檔）測試通過。

## Phase 2: MVP 基本瀏覽器 (Core Viewer)

- [x] Task 2.1: 搭建 `app-ui` egui 視窗與自訂暗色主題
  - **驗收條件**: 視窗啟動無白屏；載入等寬/無襯線現代字型；視窗佈局包含選單列、中央畫布、底部列與側邊欄容器。
  - **驗證方式**: `cargo run -p app-ui` 視窗正常顯示，冷啟動 < 50ms。
  - **預估規模**: M (3-4 檔案)

- [x] Task 2.2: 實作 GPU 加速之圖片視口畫布 (平移、滾輪縮放、最適視窗)
  - **驗收條件**: 支援滑鼠拖曳平移、滾輪依游標位置縮放、雙擊重設為 100% 或「符合視窗」；60 FPS 以上流暢更新。
  - **驗證方式**: 手動載入 4K 測試圖片，平移縮放無卡頓。
  - **預估規模**: M (3-4 檔案)

- [x] Task 2.3: 實作檔案列表導覽與底部 Filmstrip 縮圖列
  - **驗收條件**: 自動掃描當前檔案所在目錄；支援快捷鍵（左/右方向鍵、PageUp/Down）；底部預覽列非同步生成並快取縮圖。
  - **驗證方式**: 在包含 500+ 張圖片之目錄測試快速切換與縮圖列滑動。
  - **預估規模**: M (4-5 檔案)

## Phase 3: 非破壞式微調與雙圖比較 (Editing & Comparison)

- [x] Task 3.1: 實作側邊微調面板與即時預覽防抖佇列
  - **驗收條件**: 提供色溫、色調、亮度、對比、飽和度五個滑桿；連續拖曳時僅執行最新請求；提供「重設」、「取消」與「套用」。
  - **驗證方式**: 拖動滑桿時畫布即時反饋，點擊「取消」立即還原底圖且不記錄歷史。
  - **預估規模**: M (3-4 檔案)

- [x] Task 3.2: 串接 Undo/Redo 快捷鍵與原子儲存
  - **驗收條件**: Ctrl+Z 復原、Ctrl+Y 重做；Ctrl+S 原子覆寫目前檔案、Ctrl+Shift+S 另存新檔；未儲存狀態標記同步顯示於標題列。
  - **驗證方式**: 編輯後 Ctrl+S，確認目標檔案正確更新且原圖備份機制有效。
  - **預估規模**: S (2-3 檔案)

- [x] Task 3.3: 實作雙圖分割同步比對視圖 (Side-by-Side Comparison)
  - **驗收條件**: 左右並排顯示（左側原圖/參考圖，右側目前編輯）；可開關「同步縮放與平移」；同步時無雙向回授死循環。
  - **驗證方式**: 載入外部參考圖，開啟同步縮放，確認兩圖依正規化中心座標精確對齊。
  - **預估規模**: M (3-4 檔案)

### Checkpoint 3: 編輯與比對功能檢查點

## Phase 4: 重複圖片檢查器與壓縮包支援 (Duplicate Finder & Archive)

- [x] Task 4.1: 實作 `duplicate-finder` 多執行緒雜湊與 Union-Find 分群
  - **驗收條件**: 整合 MD5 與 pHash (DCT) 平行計算；Union-Find 依 Hamming distance 門檻自動聚類。
  - **驗證方式**: 單元測試 `cargo test -p duplicate-finder`（1,000 筆資料分群時間 < 100ms，實際 ~20ms）。
  - **預估規模**: M (3-4 檔案)

- [x] Task 4.2: 實作重複圖片檢查器 GUI 面板與安全刪除
  - **驗收條件**: 獨立彈出視窗；顯示掃描進度；樹狀群組列表；點擊顯示左右比對預覽；使用 `trash` crate 將重複檔案移至資源回收桶。
  - **驗證方式**: 單元測試 `cargo test -p app-ui --test duplicate_ui_test` 驗證批次智慧勾選與安全移至回收桶成功。
  - **預估規模**: L (5-6 檔案)

- [x] Task 4.3: 實作 `core-archive` 壓縮檔安全讀取與 Filmstrip 整合
  - **驗收條件**: 支援 7z / zip 格式；啟用 `sevenz-rust` 之 `aes256` feature 完整支援密碼保護 7z；防範 Path Traversal；解壓至受管理暫存目錄並自動列入導覽；壓縮檔內圖片禁用覆寫；開啟失敗或需要密碼時主動彈出密碼對話框與狀態列反饋。
  - **驗證方式**: 單元測試 `cargo test -p core-archive` 與 `cargo test -p app-ui --test archive_ui_test` 驗證路徑安全防護、7z 密碼解密流程與覆寫阻斷（全工作區 28 項測試全數通過）。
  - **預估規模**: M (3-4 檔案)

### Checkpoint 4: 查重與壓縮包檢查點
