# Rust Image Viewer (純 Rust 輕量高效圖片瀏覽與編輯工具)

## 簡介
本專案為使用純 Rust (\gui\ + \frame\ + \
ayon\) 開發的高效能桌面圖片瀏覽、非破壞式編輯與重複圖片管理工具。

## 特色
- **極致輕量**：單一原生二進位檔（< 15MB），冷啟動時間 < 50ms。
- **高幀率畫布**：GPU 硬體加速視口，支援超滑順滾輪縮放與拖曳平移。
- **非破壞式即時微調**：白平衡（色溫/色調）、微調（亮度/對比/飽和度）即時預覽，支援完整 Undo/Redo（記憶體指令，零磁碟 I/O 磨損）與原子儲存。
- **雙圖同步比對**：原圖對照或外部唯讀參考圖，雙向視口同步。
- **重複圖片檢查器**：多執行緒 pHash + MD5 批次計算，Union-Find 聚類分群，支援移至資源回收桶。
- **壓縮檔支援**：直接唯讀預覽 7z / zip 壓縮包內圖片。

## 專案結構 (Cargo Workspace)
- \crates/core-image\：影像解碼、EXIF 校正、Rayon 平行微調管線、原子存檔
- \crates/core-archive\：壓縮檔安全預覽、資源回收桶整合
- \crates/duplicate-finder\：pHash、MD5、Union-Find 分群
- \crates/viewer-state\：非破壞式 Session、In-Memory Undo/Redo
- \crates/app-ui\：桌面應用進入點與 egui 畫布元件
- \
ef_algorithms/\：自舊專案移植之演算法參考資產

## 開發與進度

v0.7.0 開發版：展開右側「調整 → 色調曲線」，選擇 RGB／紅／綠／藍通道；點擊新增、拖曳或輸入數值，選取內點後可刪除；預設自動形成平滑曲線，亦可切換折線。預覽滿意後按「套用」，可復原／重做。「工具 → 匯入／匯出調色預設集」以 JSON 保存微調與曲線；匯入僅產生預覽，不改原圖。[曲線與預設集契約](docs/SPEC_TONING_PRESETS.md)。

v0.6.1 介面排版：底部固定兩列，載入提示不改變圖片顯示大小；右側提供「調整／資訊」分頁，資訊可另開浮窗。縮圖列可拖曳上緣調整高度並記住設定；歷史用量改在文件狀態提示與資訊面板查看。主要選單與深色樣式統一。[排版規格與驗收](docs/UI_LAYOUT_REVIEW.md)。

v0.6.0 開發版：由「編輯 → 裁切圖片／變更圖片尺寸」建立草稿，套用後可復原；改尺寸可先預覽。由「檔案 → 匯出副本」選擇 PNG 或 JPEG、品質與透明背景色，確認後背景輸出，來源與儲存狀態不變。圖片資訊顯示 EXIF 拍攝時間／時區與來源方向；載入時自動校正旋轉或鏡像，不改原始照片。歷史最多 20 步，另受 512 MiB 軟預算限制；必要影像、預覽、背景工作及 GPU 可能使整體記憶體超出此值。[功能契約與驗收邊界](docs/SPEC_EDITING_OUTPUT.md)。

v0.5.2 提供「檢視 → 縮放取樣」的快速／高品質／像素模式。預設高品質，縮放或拖曳停止 150 毫秒後背景雙三次重繪可見區域；模式會記住，主圖及雙圖比較共用，原圖與儲存結果不變。[取樣規格及驗收邊界](docs/SPEC_HIGH_QUALITY_ZOOM.md)。

v0.5.1 便利操作：由「檢視」開啟唯讀資訊、F5 重新整理、空白鍵播放／停止全螢幕幻燈片、Delete 移至回收桶；「編輯」提供 90 度旋轉／翻轉與複製路徑（Ctrl+Shift+C）。旋轉可 Undo／Redo，JPEG 儲存會提示重新壓縮；預設刪除前確認，無回收桶則拒絕刪除。幻燈片間隔、循環、隨機及刪除確認可由「檢視」調整。[完整契約及待驗項目](docs/SPEC_VIEWING_CONVENIENCE.md)。

開發工具鏈固定為 Rust 1.99.1（最低支援版本），由 `rust-toolchain.toml` 選用；Windows 需具備 Visual Studio C++ Build Tools 與 Windows SDK。

v0.5.0 整合開發版已納入 v0.4.0 資源治理：縮圖快取有容量與數量上限，同目錄切圖可重用；顯示依視口與縮放分級，放大時背景擷取需要的細節，輸出保留完整解析度。GIF／WebP 動畫目前僅顯示第一格，輸出前會要求確認轉為靜態圖。

啟動可指定圖片、資料夾或壓縮檔，也可從選單開啟資料夾及最近項目：

```powershell
./target/release/app-ui.exe --portable 'D:\相片 資料夾'
./target/release/app-ui.exe 'D:\相片\圖2.png'
```

「檢視 → 排序」提供自然檔名、修改日期、檔案大小與降冪，保持目前選取並記住偏好。F11 切換全螢幕，滑鼠移動顯示兩秒資訊浮層；Esc 先關閉對話框再離開全螢幕。F1 可查看與實際派送共用定義的快捷鍵說明。

多視窗共用設定時，以最後成功關閉者的一般設定為準；最近清單在跨行程鎖內合併，不互相覆蓋。舊設定自動相容載入；新 schema 2 不會由舊版程式覆寫。詳細契約見 [資源與瀏覽規格](docs/SPEC_BROWSING_RESOURCES.md)，量測方法與已知效能取捨見 [資源量測](docs/RESOURCE_MEASUREMENTS.md)。

圖片、參考圖解碼與目錄掃描在背景執行；連續切圖只接受最新請求。儲存採已套用影像的快照，完成前暫停編輯與切圖；儲存失敗或取消另存會保留目前工作。

偏好設定預設存於 `%APPDATA%/rust_image_viewer/config.json`，使用 `app-ui.exe --portable` 時改存於執行檔旁。設定包含視窗大小與最大化、面板、直方圖、放大鏡及微調區塊開關，採背景原子寫入。損毀或不支援的設定版本會保留原檔，該次啟動使用預設值並停止寫入設定。

狀態列分別顯示目前預覽與底圖的儲存狀態。預覽必須先「套用」，才能以 `Ctrl+S` 儲存。可拖曳或輸入縮放百分比，使用 `＋`／`−` 調整倍率、`1` 切回原始尺寸、`F` 或 `0` 符合視窗；輸入數字時暫停切圖與縮放快捷鍵。微調面板可垂直捲動，底部保留套用與取消操作。
